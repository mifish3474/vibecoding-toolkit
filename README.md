# Mr. Fish's Vibe Coding Toolkit

A lightweight, static multi-page resource site for educators learning to build custom tools with AI.

## Deployment

Designed for **Cloudflare Pages** (Git integration):
- Repository: `mifish3474/vibecoding-toolkit`
- Production branch: `main`
- Framework preset: None
- Build command: leave blank
- Build output directory: `.` (repository root)

After the first deployment, add `vibecoding.mrfish.app` under Cloudflare Pages → Custom domains. This repository does not change DNS for the existing `layout` or `stopwatch` subdomains.
